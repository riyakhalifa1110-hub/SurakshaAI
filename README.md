# 🛡 SurakshaAI

> **AI-Powered Financial Fraud Detection Platform for Rural India**

SurakshaAI is an AI-powered cybersecurity platform developed to protect users from modern digital financial fraud. It helps identify SMS scams, WhatsApp scams, phishing websites, fake UPI requests, and fraudulent phone calls using Artificial Intelligence.

---

# 📌 Problem Statement

Millions of people become victims of online financial fraud every year because they cannot identify fake SMS messages, phishing websites, scam calls, or fraudulent UPI requests.

SurakshaAI provides an intelligent assistant that analyzes suspicious content and explains the risk in simple language before users become victims.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/riyakhalifa1110-hub/SurakshaAI.git
```

Move into the project

```bash
cd SurakshaAI
```

Install requirements

```bash
pip install -r requirements.txt
```

Run the application

```bash
python run.py
```

Open

```
http://127.0.0.1:5000
```

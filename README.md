# SurakshaAI

AI-powered Financial Fraud Detection Platform

## Features
- SMS Scam Detection
- WhatsApp Scam Detection
- UPI Fraud Detection
- URL Phishing Detection
- Call Scam Detection
- OCR Screenshot Analysis
- Voice Input
- Multilingual Support (English, Hindi, Gujarati)

## Tech Stack
- Python
- Flask
- Groq Llama 3.3
- HTML/CSS/Bootstrap
- JavaScript
- Tesseract OCR
